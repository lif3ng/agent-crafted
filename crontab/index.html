📐 Cron 表达式格式

🔤 特殊字符

符号含义示例
*任意值* * * * * = 每分钟
,列举多个值0 9,18 * * * = 每天9点和18点
-范围0 9-17 * * * = 每天9到17点
/步长*/15 * * * * = 每15分钟
L最后（日/周）0 0 L * * = 每月最后一天
W最近工作日0 0 15W * * = 最接近15号的工作日
#第几个星期几0 0 * * 5#3 = 第3个周五

📋 常用示例

*/5 * * * *每5分钟
0 */2 * * *每2小时
0 0 * * *每天午夜
0 2 * * *每天凌晨2点
0 0 * * 0每周日午夜
0 0 * * 1每周一午夜
0 0 1 * *每月1号午夜
0 8 * * 1-5工作日早8点
30 4 * * 6每周六凌晨4:30
0 0 1 1 *每年1月1日
0,30 * 1,15 * *1号和15号每半小时

💡 特殊字符串（简写）

简写等价于含义
@yearly0 0 1 1 *每年一次
@monthly0 0 1 * *每月一次
@weekly0 0 * * 0每周一次
@daily0 0 * * *每天一次
@hourly0 * * * *每小时一次
@reboot—每次启动时

🖥️ 常用命令

命令说明
crontab -e编辑当前用户的 crontab
crontab -l列出当前用户的定时任务
crontab -r删除当前用户的所有定时任务
crontab -u user -l查看指定用户的定时任务
crontab filename从文件导入定时任务
💡 提示：crontab 文件中可以设置环境变量：
SHELL=/bin/bash
PATH=/usr/local/bin:/usr/bin
MAILTO=your@email.com
日志重定向：*/5 * * * * /path/to/script.sh >> /var/log/my.log 2>&1
